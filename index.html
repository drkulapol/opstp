ตรวจสอบลูกหนี้รายตัวสิทธิ STP เทียบ REP (OPD)

จับคู่ด้วย HN + วันที่รับบริการ · ใช้ VN = SEQ ช่วยตัดสินเมื่อวันเดียวกันมีหลาย visit · ประมวลผลในเบราว์เซอร์ ไม่มีการส่งข้อมูลออก

คู่มือดึงข้อมูลลูกหนี้ STP จาก HOSxP XE (SQL)

ขั้นตอน

  1. กดปุ่ม คัดลอก SQL ด้านล่าง
  2. แก้ช่วงวันที่ในบรรทัดแรก ๆ (CTE params): d1 = วันเริ่ม, d2 = วันสิ้นสุด (รูปแบบ YYYY-MM-DD ปี ค.ศ.) ค่าตั้งต้นคือปีงบ 2569: 2025-10-01 ถึง 2026-09-30
  3. รันใน HOSxP XE (เมนู SQL Query) หรือโปรแกรมที่ต่อ PostgreSQL ของ HOSxP ได้ เช่น pgAdmin / DBeaver
  4. Export ผลลัพธ์เป็น Excel (.xls/.xlsx) หรือ CSV ห้ามเปลี่ยนชื่อคอลัมน์ (หน้าเว็บอ่านจากชื่อ hn, visit_date, vn)
  5. ลากไฟล์ที่ได้มาวางในหน้านี้พร้อมไฟล์ REP (.xls หรือ .zip)

คอลัมน์ที่ได้

คอลัมน์ความหมาย
visit_dateวันที่รับบริการ (ovst.vstdate) ใช้จับคู่กับ “วันเข้ารักษา” ใน REP
hnHN ใช้จับคู่กับ HN ใน REP (หน้าเว็บตัดเลข 0 นำหน้าให้เอง)
first_name, last_nameคำนำหน้า+ชื่อ, นามสกุล
pttype, pttype_nameสิทธิหลักของ visit
claim_fundกลุ่มรายการที่เบิกได้ครบเงื่อนไข เช่น ADP claim list (41003,51410), HIV drug (…), Drug J2 (…)
check_statusCOMPLETE = ข้อมูลครบ, INCOMPLETE = ยังขาดรหัสประกอบการเบิก
missing_detailรายการที่ขาด เช่น 56xxx -> missing H9339
vnVN ซึ่งตรงกับ “รหัสบริการ (SEQ)” ใน REP ใช้ตัดสินเมื่อวันเดียวกันมีหลาย visit

หลักการของ SQL

  • เลือก visit: OPD (ไม่มี AN) ในช่วงวันที่ ที่สิทธิหลักหรือสิทธิใน visit_pttype มี hipdata_code หรือ nhso_code = STP
  • รวบรวมข้อมูลต่อ visit: ICD10 (ovstdiag), รหัส ADP ของค่าบริการ (opitemrece + nondrugitems.nhso_adp_code), รหัส PP special
  • จับกลุ่มยา: อ่านชื่อและความแรงจาก drugitems แล้วเทียบด้วย regex ตามตัวยาสำคัญ ได้แก่ ยาต้านไวรัส HIV, Clopidogrel, ยา จ(2), Antidote และยาขับเหล็ก (D56) ถ้ามียาที่จับไม่ได้ ให้เพิ่ม icode ใน CTE drug_manual (แทน 'XXXXXXX')
  • กฎตรวจความครบ (rule_hit): ถ้ามีรายการหลัก ต้องมีรหัสประกอบด้วย เช่น
    • TB (A15–A19): CXR → CXRTB, 35001 → T3310, 36018 → T2130, ต้องมี FOLLOWTB
    • HIV (B20–B24): แล็บ 30101/32202/32203/32501/32502/30509/36362 → รหัส LAB…F1/LABCD4/LABVL
    • Thalassemia (D56): 30104 → TDT_HCT, 30306 → TDT_SEF
    • กายภาพ 56xxx → H9339
    • จิตเวช F00–F99 → ต้องมีอย่างน้อย 1 ใน H9449.1/H9449.2/H9433.1/H9433.2
    • ANC Z34–Z36: 30313 → TLM_LTYP
  • รายการเบิกทั่วไป: รหัส ADP ที่อยู่ในรายการ biglist (บริการ/แล็บ/X-ray/หัตถการ/อุปกรณ์/DRUGP/TELMED/FP ฯลฯ), รหัส H/S list และคัดกรองมะเร็งปากมดลูกในหญิงอายุ 15–59 ปี (1B004…)
ข้อควรรู้: SQL นี้ส่งออกเฉพาะ visit STP ที่มีรายการเบิกได้อย่างน้อย 1 กฎ (เพราะ JOIN agg) visit STP ที่ไม่มีรายการเบิกแยกจะไม่อยู่ในรายการลูกหนี้ ดังนั้น REP ที่หน้าเว็บขึ้นว่า “ไม่มีในลูกหนี้” อาจเป็น visit ที่รหัสรายการยังไม่อยู่ใน biglist ควรเพิ่มรหัสนั้นใน biglist แล้วรันใหม่ ถ้าต้องการให้ส่งออกทุก visit STP ให้เปลี่ยน JOIN agg a เป็น LEFT JOIN agg a
